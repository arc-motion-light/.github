# ARC Motion & Light — GitHub organization profile

This repository contains the profile content for the [ARC Motion & Light GitHub organization](https://github.com/arc-motion-light).

GitHub displays [profile/README.md](profile/README.md) on the organization's overview page. That file introduces ARC's technology, educational ambitions and invitation to collaborate. This root README explains how the profile repository is organized.

The broader engineering documentation belongs in the separately maintained `arc-open-development` repository. It is not a replacement for this organization-profile repository.

## Profile files

- [profile/README.md](profile/README.md): the organization-profile presentation.
- [profile/assets/arc-logo.png](profile/assets/arc-logo.png): the existing official ARC mark used in that presentation.
- [assets/branding/arc-logo-icon.png](assets/branding/arc-logo-icon.png): a square version prepared for the organization avatar; repository content does not configure the live avatar.

Updates should preserve this repository's existing Git history and unrelated files. Private preparation notes and development archives are excluded from the public files. Publication and live organization-setting changes require explicit authorization.
